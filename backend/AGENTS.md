# Backend agent rules

Extend root [`AGENTS.md`](../AGENTS.md). `app/main.py` and its test suite are the operational contract. Do not change externally visible endpoint paths/response fields without coordinated frontend changes and tests. Preserve maximum upload size, 25M-pixel cap, MIME + actual decoded format checks, safe `torch.load(weights_only=True)`, strict state-dict loading, exact three-class order, and image preprocessing. Do not silently fallback to mock predictions when checkpoint loading fails. Keep error messages actionable but avoid leaking production secrets. Maintain local backend port 8011; note that port 8000 belongs to an unrelated service. Run `backend/.venv/Scripts/python.exe -m pytest -q` from `backend/`. Security review is required for any external deployment.
